**Fernanda Guerra** (GitHub `feeeeeda`, `fguerrafgr@gmail.com`) contribui no leme-app
e é esposa do Glauco. Por isso é normal aparecer commit dela em branch que o Glauco
tem checkada localmente, e vice-versa — não é branch de outra pessoa que ele pegou
emprestada.

**Why:** em 04/09/2026, ao terminar a limpeza do Tour que o commit dela tinha deixado
pela metade (PR #594), ofereci escrever um comentário no PR explicando o que faltava.
O Glauco dispensou: "ela é minha esposa, eu aviso aqui a ela".

**How to apply:** não propor comentário de PR, review formal ou qualquer notificação
via GitHub para alinhar algo com ela — o caminho é o Glauco falar direto. Continuar
reportando a ele o que achei no código dela normalmente, com o mesmo rigor de sempre;
o que muda é só o canal, não o conteúdo. Não confundir com a "Fernanda ('o Fer')" que
convida a tech a apresentar no All Aboard em [[all-aboard-e-mensal]] — não confirmei
se é a mesma pessoa.
