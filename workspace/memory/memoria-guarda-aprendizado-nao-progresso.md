A memória do workspace guarda **aprendizado**: armadilha técnica, regra de trabalho,
decisão de produto e o porquê de cada uma. **Andamento de feature não entra**: em que
branch está, qual PR está aberto, o que falta testar, se já foi para prod.

**Why:** em 06/11/2026, na importação das memórias do notebook, o Glauco pediu para
tirar as memórias de OMR e da folha v2 (estado de feature que envelhece rápido), mas
manter as lições que vinham junto.

**How to apply:** ao salvar memória, escrever a lição de forma que continue verdadeira
depois que a feature terminar. Se o fato só descreve onde o trabalho está, não salvar.
Uma memória que mistura os dois tem a parte de progresso cortada. Andamento, se
precisar, vai em `notes/projetos/`.
